CODE FINDINGS TO RECHECK
- src/utils/geometry.ts assigns idx per pair of route geometry coordinates.
  useRouteDragging passes that index to insertShapingPoint, but the store treats
  it as a position between hard waypoints. Shaping points can be omitted.
- route.service.ts hardcodes cycling-road, which is appropriate to the scope.
  It strips intermediate bearings; sticky two-leg handling is a special case.
- Sticky shaping handles only two hard waypoints and one shaping point.
- Moving a hard waypoint clears all shaping points under the existing behavior.
- Routing lacks cancellation/revision protection; old responses can overwrite
  newer edits. The throttle is created within each getRoute call.
- useRouteCalculation watches whole waypoint objects, including geocoding state.
